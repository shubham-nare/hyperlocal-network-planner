How to check a point accurately (exact location, no name search)
  1. Open the app's website in Chrome or Edge and press F12, then ⋮ → More tools → Sensors.
  2. Under Location, choose Other… and paste the latitude (L) and longitude (G) shown below.
  3. On the website, click Detect my location (allow location access if asked).
  4. Check the address the site shows is in the same area as the place name, then record 1 / 2 / 3.

Why: searching by name is ambiguous (there are several "Kuvempu Nagar"s), so it can silently check the wrong place.
